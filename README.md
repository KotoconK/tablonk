# TablonK Advance

Tablón de escritorio para Windows: notas y tareas tipo post-it, pizarra con nodos y conexiones, calendario y tabla de eventos. Hecho con Python, Tkinter y Pillow.

## Secciones

* **Notas y tareas**: post-its en una rejilla redimensionable, con formato de texto y listas de tareas.
* **Pizarra**: nodos de texto, imágenes, conexiones y lápiz; exporta a PNG.
* **Calendario**: vistas de día, semana, mes y año. Cada evento usa el color de su tipo.
* **Eventos**: tabla con columnas personalizables, buscador, filtros por tipo y prioridad, y eventos fijados en la barra lateral.

Todo se guarda en un `config.json` por proyecto.

## Descargar

Descarga `TablonKAdvance.exe` de la [última release](https://github.com/KotoconK/tablonk/releases/latest). Una vez instalado, las nuevas versiones se instalan desde **Configuración → Actualizaciones**.
